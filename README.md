# 摸鱼助手（adfish）

<p align="center">
  <img src="assets/adfish-icon.png" width="120" alt="adfish 图标">
</p>

一个外观类似小广告的 Windows 桌面浏览器。默认位于屏幕右下角，支持悬停浏览、隐身模式、多种主题和自动保存设置。

支持 **Windows 10/11 64 位（x64、ARM64）**。

## 安装与运行

### 下载发布版

1. 在仓库 **Releases** 下载 Windows 发布包并完整解压。
2. 双击对应架构目录中的 **adfish.exe**；统一双架构包也可通过 **启动.cmd** 自动选择架构。
3. 统一包可双击 **创建快捷方式.cmd**，创建名为 **adfish** 的桌面快捷方式。

无需安装 Node.js 或 WebView2。请保留 EXE 旁的全部资源文件，不要只复制 EXE。创建快捷方式后移动程序目录，需要重新创建快捷方式。

### 从源码运行

安装 **Node.js 22.12 或以上版本**，下载或克隆源码，在项目目录执行：

```powershell
npm ci
npm start
```

首次安装依赖需要联网。安装后也可双击源码目录的 **启动.cmd**；双击 **创建快捷方式.cmd** 可创建 adfish 桌面快捷方式。

如果 PowerShell 提示无法运行 `npm.ps1`，改用 `npm.cmd ci` 和 `npm.cmd start`。

## 操作说明

- **进入网页：** 点击广告中的「探索精选」，或将鼠标移入顶部栏下方的内容区。
- **返回广告：** 点击左上角图标或标题。默认悬停模式下，移到顶部栏或窗口外也会显示广告。
- **浏览菜单：** 点击右上角「⋯」，可打开网址、后退、前进、刷新、调节音量、静音、置顶和打开设置。鼠标进入菜单后移出，菜单自动收起。
- **访问网站：** 在网址输入框填写网址或关键词，按回车访问；关键词使用 Bing 搜索。
- **移动与缩放：** 拖动顶部栏空白处移动，拖动边缘调整大小，也可在设置中输入尺寸。双击边框不会最大化。
- **主题与设置：** 在设置中选择科技蓝、自然绿、活力红或暖琥珀，修改主页和广告文案。所有有效修改自动保存，无需点击保存。
- **网页缩放：** 默认随窗口等比例缩放，文字较小时可增大窗口或在设置中关闭缩放。
- **隐身模式：** 默认关闭。在设置中开启后，移出窗口和菜单会隐藏整个窗口，鼠标回到原位置时恢复。隐藏不会关闭网页或自动静音；手动最小化需通过任务栏恢复。

### 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + L | 输入网址 |
| Ctrl + Shift + A | 切换广告与网页 |
| F5 / Ctrl + R | 刷新 |
| Alt + ← / Alt + → | 后退 / 前进 |
| Esc | 关闭菜单、网址输入或设置 |

设置和登录数据默认保存在程序旁的 `data` 目录，目录不可写时使用 `%APPDATA%/AdWindow`。网站登录是否持续有效取决于网站策略；程序不提供密码管理器，重启后不自动恢复上次网址。分享程序时不要包含个人 `data` 目录。
